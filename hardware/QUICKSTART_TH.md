# คู่มือเริ่มต้นใช้งาน ESP32 Keypad Music Player

## 🎯 สรุปโครงการ

โปรเจคนี้เป็นเครื่องเล่นดนตรีด้วย ESP32 ที่ใช้ปุ่มกด 4x4 (16 ปุ่ม) เป็นคีย์บอร์ดดนตรี และส่งเสียงผ่านโมดูล I2S Audio

## ⚠️ ปัญหาที่พบบ่อย

**"ตอนนี้เหมือน keypad มันไม่ตรง"** - ถ้าคุณพบปัญหานี้ แปลว่าการตั้งค่าขาของ keypad ไม่ตรงกับฮาร์ดแวร์จริง

## 🔧 วิธีแก้ปัญหา keypad ไม่ตรง

### ขั้นตอนที่ 1: ใช้ Keypad Detector หาค่าที่ถูกต้อง

1. เปิดไฟล์ `hardware/keypad_detector/keypad_detector.ino` ใน Arduino IDE
2. อัปโหลดโปรแกรมลง ESP32
3. เปิด Serial Monitor (ตั้งค่า baud rate = 115200)
4. เลือกโหมด **1** (Auto-detect configuration)
5. กดปุ่ม 1, 2, 3, A บน keypad ตามที่โปรแกรมบอก
6. รอจนโปรแกรมหาการตั้งค่าที่ใช้งานได้
7. บันทึกค่า rowPins และ colPins ที่โปรแกรมแสดง

### ขั้นตอนที่ 2: นำค่าที่ได้ไปใช้กับโปรแกรมหลัก

1. เปิดไฟล์ `hardware/music_player/music_player.ino`
2. แก้ไขบรรทัดนี้ให้ตรงกับค่าที่ detector หาเจอ:

```cpp
// ตัวอย่าง: ถ้า detector บอกว่าใช้ขาเหล่านี้
byte rowPins[ROWS] = {33, 32, 13, 12};  // แก้ตรงนี้
byte colPins[COLS] = {21, 15, 27, 14};  // แก้ตรงนี้
```

3. อัปโหลดโปรแกรมใหม่
4. ทดสอบกดปุ่มดู ควรจะทำงานถูกต้องแล้ว

## 📱 โหมดการตรวจจับใน Keypad Detector

### โหมด 1: Auto-detect (แนะนำ)
- ทดสอบการตั้งค่าที่ใช้บ่อย 5 แบบโดยอัตโนมัติ
- ใช้งานง่าย แค่กดปุ่มตามที่บอก
- เหมาะสำหรับผู้ใช้ทั่วไป

### โหมด 2: Test specific configuration
- ทดสอบการตั้งค่าที่คุณระบุเอง
- เหมาะสำหรับผู้ที่รู้ว่าใช้ขาอะไร
- ต้องใส่ขาทั้ง row และ column เอง

### โหมด 3: Scan all pins
- สแกนหาว่าขาไหนมีสัญญาณเมื่อกดปุ่ม
- เหมาะสำหรับการหาปัญหา
- ช่วยระบุว่าขาไหนต่อกับ keypad

### โหมด 4: Test current config
- ทดสอบการตั้งค่าจากโค้ดหลักแบบเร็ว
- เหมาะสำหรับการ debug

## 🎵 การใช้งาน Music Player

### แผนผังโน้ตเพลง

```
ปุ่มบน keypad:          โน้ตที่ได้:
┌───┬───┬───┬───┐      ┌────┬────┬────┬────┐
│ 1 │ 2 │ 3 │ A │      │ Do │ Re │ Mi │ Fa │ (สูง)
├───┼───┼───┼───┤      ├────┼────┼────┼────┤
│ 4 │ 5 │ 6 │ B │      │ Fa │Sol │ La │Sol │ (สูง)
├───┼───┼───┼───┤      ├────┼────┼────┼────┤
│ 7 │ 8 │ 9 │ C │      │ Si │ Do │ Re │ La │ (สูง)
├───┼───┼───┼───┤      ├────┼────┼────┼────┤
│ * │ 0 │ # │ D │      │Sol │ Mi │ Do │ Si │ (สูง)
└───┴───┴───┴───┘      └────┴────┴────┴────┘
                        (ต่ำ) (สูง)(สูงมาก)(สูง)
```

### ความถี่แต่ละโน้ต

- **1** = Do (C4, 262 Hz)
- **2** = Re (D4, 294 Hz)
- **3** = Mi (E4, 330 Hz)
- **4** = Fa (F4, 349 Hz)
- **5** = Sol (G4, 392 Hz)
- **6** = La (A4, 440 Hz)
- **7** = Si (B4, 494 Hz)
- **8** = Do สูง (C5, 523 Hz)
- **9** = Re สูง (D5, 587 Hz)
- **0** = Mi สูง (E5, 659 Hz)
- **\*** = Sol ต่ำ (G3, 196 Hz)
- **#** = Do สูงมาก (C6, 1047 Hz)

## 🔌 การต่อสายฮาร์ดแวร์

### โมดูล I2S Audio (เช่น MAX98357A)

| ขาของโมดูล | ขาของ ESP32 | หมายเหตุ |
|------------|-------------|---------|
| BCLK       | GPIO 25     | Bit Clock |
| LRC        | GPIO 26     | Left/Right Clock |
| DIN        | GPIO 16     | ข้อมูลเสียง |
| VIN        | 3.3V        | ไฟเลี้ยง |
| GND        | GND         | กราวด์ |

### Keypad 4x4

**การต่อสายขึ้นอยู่กับ keypad ของคุณ!**

ค่าเริ่มต้น (ถ้าไม่ได้ผลให้ใช้ detector):

| ขาของ Keypad | ขาของ ESP32 | ประเภท |
|-------------|-------------|--------|
| Row 1       | GPIO 33     | แถว 1  |
| Row 2       | GPIO 32     | แถว 2  |
| Row 3       | GPIO 13     | แถว 3  |
| Row 4       | GPIO 12     | แถว 4  |
| Col 1       | GPIO 21     | คอลัมน์ 1 |
| Col 2       | GPIO 15     | คอลัมน์ 2 |
| Col 3       | GPIO 27     | คอลัมน์ 3 |
| Col 4       | GPIO 14     | คอลัมน์ 4 |

## 💡 Tips และคำแนะนำ

### เมื่อ keypad ไม่ทำงาน
1. ใช้ keypad_detector หาค่าที่ถูกต้อง (โหมด 1)
2. ถ้าหาไม่เจอ ลองโหมด 3 เพื่อดูว่าขาไหนมีสัญญาณ
3. ตรวจสอบการต่อสาย อาจจะหลวมหรือต่อผิดขา
4. ลองสลับลำดับ row pins หรือ col pins

### เมื่อกดปุ่มแล้วได้โน้ตผิด
- ลำดับขาอาจจะไม่ถูกต้อง
- ใช้ detector โหมด 1 หาค่าใหม่
- row pins และ col pins อาจจะสลับกัน

### เมื่อไม่มีเสียง
1. ตรวจสอบการต่อสายโมดูล I2S
2. ตรวจสอบว่าโมดูลได้ไฟหรือไม่
3. ตรวจสอบว่าต่อลำโพงหรือหูฟังแล้วหรือยัง
4. ดูใน Serial Monitor ว่ามีข้อความ error หรือไม่
